# Profile photo

The portfolio uses one portrait file in this folder: `opeyemi.jpg`.

To replace it, save the new photo here with exactly that name, then commit and push.

- Format: JPG (if you switch to WebP, update the image paths in `portfolio.html`)
- Shape: square or close to it, with your face centred
- Size: at least 1200px on the long side, under 400KB

If the file is ever missing, the page shows an "OI" monogram in the same frame instead.
